Forum thread: https://www.beamng.com/threads/improved-lamborghini-gallardo-v1-27.80412/

## How to format the files

Simply format the `jbeam` into `cjson` and the `cs` into `torquescript` on Visual Studio Code

```json
{
    "files.associations": {
        "*.jbeam": "cjson",
        "*.cs": "torquescript"
    }
}
```
